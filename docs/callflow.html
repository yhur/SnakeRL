SnakeRL: call flow

Both flows start in main.py, build the same Trainer (a Snake game, a DQN agent and its replay memory), and drive it one move at a time. Headless calls it in a plain loop with 8 games at once; the dashboard calls it from a Qt timer and draws every move.

1 · Headlesspython main.py --headless
train 8 games at once as fast as possible, print a line per game, save every 50 episodes 2 · Dashboardpython main.py
one game, moved by a 16 ms Qt timer at the chosen speed, drawn after each tick

On the right of each line, file:line opens the source where that step happens, and def opens the function itself, in a panel on the right (Esc closes it). Click a coloured block to fold it. Small helper calls are left out.

1Headless call flow

main() builds the trainer, wraps it in a ParallelTrainer (8 games by default), and hands it to headless.train(), which loops step() until the episode count is reached or Ctrl+C.

  • main()parse the options, then build the trainer
    • Config.load_last()sharedsettings.json, or the defaults
    • if--load continue from a checkpoint
      • checkpoint.load()shared
        • settings.with_brain_of(saved)network shape from the file, the rest from settings
        • DQNAgent(cfg)→set_weights()model and target from the file
        • restore epsilon and the move / training counters
        • Trainer(cfg, agent)
        • arrays_to_history()the history columns back into a list of dicts
    • elsea new, untrained agent
      • Trainer(settings)shared
        • SnakeEnv(cfg)→Board(), Snake()
        • DQNAgent(cfg)
          • build_network() ×2model, and the frozen target_model
          • ReplayMemory(memory_size)
        • start_episode()→env.reset()
    • if--games > 1 default 8
      • ParallelTrainer.from_trainer()same agent and history, 8 SnakeEnv games
    • headless.train(trainer, episodes, save)
      • loopeach round until -e episodes, or Ctrl+C
        • trainer.step()ParallelTrainer: one move in every game
          • agent.choose_actions(states)→model.predict_on_batch()one network call for all 8; random with chance epsilon
          • loopfor each of the 8 games
            • env.step(action)shared
              • snake.moveTo(ACTIONS[action])'ok', 'apple', 'wall', 'body' or 'starved'
              • ifapple reward_apple
                • board.generate_apple()
              • wall / body / starved: reward_death, done
              • get_state()→vision_state() or simple_state()
            • agent.remember()→memory.add()shared
          • agent.learn(moves=8)shared
            • iftraining due and the memory holds a batch
              • train_on_batch(*memory.sample(64 × 8))
                • model.predict_on_batch(states)current Q-values
                • target_model.predict_on_batch(next_states)
                • target = reward + gamma × max Q(next), only for the move made
                • model.train_on_batch(states, targets)one Adam step; returns the loss
            • ifanother 500 moves passed
              • target_model.set_weights(model.get_weights())
          • loopfor each game that just ended
            • record_game()sharedhistory entry, best score
              • agent.end_episode()epsilon × 0.97, down to epsilon_min
            • env.reset()→board.reset()a new game in that slot
        • loopfor each game that just ended
          • print(episode, score, best, avg, epsilon, loss, moves/s, status)
          • ifevery 50 episodes
            • checkpoint.save()shared
              • history_to_arrays()
              • np.savez(config, progress, weights, history)
      • exceptCtrl+C stop the loop
        • print a newline, fall through to the final save
      • checkpoint.save()always, at the end

One learn() per round, not per game: with 8 games each training step uses 512 memories. The target network refresh counts moves, so it happens about every 62 rounds.

2Dashboard call flow

main() builds the same Trainer (one game), opens the window and enters Qt's event loop. From then on everything is a callback: the timer moves the snake, keys and buttons steer, and Qt repaints the views.

  • main()
    • Config.load_last()shared
    • Trainer(settings) or checkpoint.load()sharedas in flow 1
    • QApplication()
    • Dashboard(trainer)
      • build_window()NetworkView, BoardView, ChartView, ConfigPanel, buttons
      • installEventFilter()catch Space / R / Q anywhere
      • QTimer.start(16)about 60 ticks a second
      • start_game()→board.show_game(env)
    • app.exec_()Qt's event loop: runs until the window closes
      • eventtimer tick, every 16 ms → on_timer()
        • ifpaused return: Space moves instead
          • do nothing this tick
        • loopfor each move owed speed × elapsed; Max: moves for 12 ms
          • one_move()
            • trainer.step()Trainer: one move in one game
              • agent.choose_action(state)→q_values()random with chance epsilon
              • env.step(action)→snake.moveTo()shared
              • iflearning off: just watch the best moves
                • agent.remember()shared
                • agent.learn()→train_on_batch(64)shared
              • keep the move for the "last move" panel
              • ifgame over
                • finish_episode()→record_game()→start_episode()shared
            • ifgame over
              • game_finished()→chart.set_history()→start_game()
        • refresh()once per tick, however many moves
          • stats: episode, moves, epsilon, memory, best, loss…
          • agent.q_values(state)the next move, and on the board while paused
          • show_last_move()→agent.best_future_q()the Bellman target of that move
          • nn_view.show_brain(agent.brain(state))weights and every layer's values
          • board.update(), nn_view.update()ask Qt to repaint
      • eventrepaint → each view's paintEvent()
        • GameBoard.paintEvent()board, snake, apple
        • BoardViewvision rays (or the 3 cells for Simple), Q-values while paused
        • NetworkView.paintEvent()
        • ChartView.paintEvent()→_sync()new episodes into arrays, one point per pixel column
      • eventkey press → eventFilter()
        • Space: pause_or_step()paused already: one_move()
        • R: resume()
        • Q: close()
      • eventApply in the settings panel → restart(cfg)
        • ifsame network shape, Keep agent
          • trainer.use_settings(cfg)→agent.apply_settings()
        • elifNew agent
          • use(Trainer(cfg))
        • cfg.save(settings.json)headless starts from these too
      • eventSave button → save()
        • checkpoint.save()sharedsaves/checkpoint_<state>_ep<N>.npz
      • eventLoad… button → load_dialog()
        • checkpoint.load()shared
        • use(trainer)

The views repaint once per timer tick, not once per move: at high speeds many moves happen between two pictures. While paused, Space goes through the same one_move(), so a single step also learns.
